វិធីទទួលបាន APK (មិនត្រូវការ Android Studio)៖
1. បង្កើតគណនី GitHub (ឥតគិតថ្លៃ) រួចបង្កើត repository ថ្មី។
2. Upload ឯកសារ/ថតទាំងអស់ក្នុង zip នេះ (រួមទាំងថត .github) ទៅ repository។
3. ចូលផ្ទាំង Actions → "Build APK" → Run workflow (ចាំប្រហែល ៥-៨ នាទី)។
4. បើករបាយការណ៍ run ដែលបានបញ្ចប់ → ទាញយក artifact "PaliKhmerDictionary-apk" (ពន្លា zip ទទួលបាន app-debug.apk)។
5. ផ្ទេរ APK ទៅទូរស័ព្ទ Android អនុញ្ញាត "ដំឡើងពីប្រភពមិនស្គាល់" រួចដំឡើង។
